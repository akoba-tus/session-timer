準備と設定

1. データベース

FirebaseのRealtime Databaseの URL を貼り付けてください（例: https://xxxx-default-rtdb.asia-southeast1.firebasedatabase.app）。

Firebase側の「ルール」には次を貼り付けてください。

{
  "rules": {
    "events": {
      "$key": {
        ".read": "$key.length >= 16",
        ".write": "$key.length >= 16"
      }
    }
  }
}

2. イベントキー

会議ごとの合言葉です。これを知っている端末だけが状態を読み書きできます。URLは会場スタッフ以外に公開しないでください。

3. プログラム

Excelから次の列の順にコピーして貼り付けてください：会場 ／ 開始時刻 ／ 発表者 ／ 演題 ／ 発表(分) ／ 質疑(分)。後ろの2列は省略可で、空欄ならiPad側の設定時間になります。見出し行はあっても構いません。

4. 各会場のiPad

iPadのカメラでQRを読み取り、Safariで開いたら共有 →「ホーム画面に追加」。以後はそのアイコンから起動します。プログラムを保存すると会場が表示されます。

5. Zoom映像に重ねる（OBS）

上の各会場の「OBS用URL」を、OBS Studioの「ブラウザ」ソースに貼り付けます。幅480・高さ150にして、その会場のZoom映像の上に置いてください。背景は透明です。
